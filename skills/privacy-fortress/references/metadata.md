# 账号、文件与 Agent 元数据

## Git 与公开仓库

- 新仓库使用平台提供的 noreply 邮箱和中性作者名；按工作/个人边界逐仓库配置。
- 发布前检查作者信息、提交消息、remote URL、issue/PR、CI 日志和 Release 附件。
- 改写历史会改变所有提交哈希并影响协作者，必须先备份和协调；本 skill 不建议仅为伪造时区而改写历史。
- 已公开的秘密不能靠删除当前文件解决：撤销/轮换凭据，再评估历史清理和第三方缓存。
- 私有仓库不等于永远私有，按未来可能公开的标准审查。

## 文件与图片

- 上传前检查 Office/PDF 作者、修订、批注、隐藏工作表、源码注释、路径、主机名和内网地址。
- 图片检查 EXIF/GPS、截图状态栏、通知、账号和背景环境。
- 日志检查公网 IP、用户目录、订阅 URL、token 和设备标识。
- 优先制作脱敏副本，不覆盖唯一原件。

## 账号

网络层无法改变服务商已掌握的手机号、支付、KYC、登录历史、Cookie 和账号行为。不要为了“画像一致”提交虚假受监管资料。减少不必要授权、撤销不用的第三方应用、分离不相关身份即可。

## AI Agent / CLI 特别边界

工具输出可能进入模型上下文。避免让 Agent 读取 `.env`、凭据、私人通讯录、完整 home 目录或无关日志；使用专用工作区和最小授权 MCP/Connector。

发布或分享会话前检查：

- 绝对路径和用户名；
- Git remote、分支、提交邮箱；
- 环境变量和命令行参数中的秘密；
- 诊断/bug 报告是否包含完整对话与文件；
- 本地文件是否被上传到第三方转换、订阅或检测服务。
